# Environment Configuration Setup Guide

## Overview

All hardcoded values have been moved to environment variables for better security and configurability. The configuration is now handled by dedicated environment validation files:

- **Frontend**: [`frontend/config/env.ts`](frontend/config/env.ts)
- **Blockchain**: [`Blockchain/config/env.js`](Blockchain/config/env.js)

## Quick Setup

### 1. Install Required Dependencies

```bash
# In the Blockchain directory
cd Blockchain
npm install dotenv

# No additional dependencies needed for frontend
```

### 2. Create Environment Files

**For Blockchain development:**

```bash
cd Blockchain
cp .env.example .env
```

**For Frontend (optional - auto-generated by deployment):**

```bash
cd frontend
cp .env.example .env.local
```

### 3. Configure Your Environment Variables

#### Blockchain Configuration (`.env`)

The Blockchain `.env` file includes:

```bash
# Network Configuration
RPC_URL=http://127.0.0.1:8545           # Your blockchain RPC endpoint
CHAIN_ID=31337                          # Network chain ID
CHAIN_NAME=Hardhat Local                # Display name for the network

# Account Configuration
MNEMONIC=test test test...               # Mnemonic for development accounts

# Frontend Integration
FRONTEND_PATH=../frontend               # Relative path to frontend directory
ENV_FILE_NAME=.env.local               # Environment file name for frontend

# Currency Configuration
CURRENCY_NAME=Ethereum                  # Native currency name
CURRENCY_SYMBOL=ETH                     # Currency symbol
CURRENCY_DECIMALS=18                    # Currency decimal places

# Deployment Configuration
DEPLOYMENT_TIMEOUT=60000                # Deployment timeout in ms
```

#### Frontend Configuration (auto-generated)

The frontend `.env.local` is automatically created when you deploy the contract, containing:

```bash
NEXT_PUBLIC_CONTRACT_ADDRESS=0x...      # Deployed contract address
NEXT_PUBLIC_NETWORK_ID=31337           # Network ID
NEXT_PUBLIC_RPC_URL=http://...         # RPC endpoint
NEXT_PUBLIC_CHAIN_ID=0x7A69            # Chain ID in hex
NEXT_PUBLIC_CHAIN_NAME=Hardhat Local   # Network name
NEXT_PUBLIC_CURRENCY_NAME=Ethereum     # Currency details
NEXT_PUBLIC_CURRENCY_SYMBOL=ETH
NEXT_PUBLIC_CURRENCY_DECIMALS=18
```

## What Changed

### Before (Hardcoded Values)

```javascript
// hardhat.config.js
module.exports = {
	solidity: "0.8.28",
	networks: {
		localhost: {
			url: "http://127.0.0.1:8545", // ❌ Hardcoded
			chainId: 31337, // ❌ Hardcoded
			accounts: { mnemonic: "test test..." }, // ❌ Hardcoded
		},
	},
};

// connectWallet.ts
const LOCALHOST_NETWORK = {
	chainId: "0x7A69", // ❌ Hardcoded
	chainName: "Hardhat Local", // ❌ Hardcoded
	rpcUrls: ["http://127.0.0.1:8545"], // ❌ Hardcoded
};
```

### After (Environment-driven)

```javascript
// hardhat.config.js
const BlockchainEnv = require("./config/env");
module.exports = {
	solidity: "0.8.28",
	networks: {
		localhost: BlockchainEnv.getNetworkConfig(), // ✅ From environment
	},
};

// connectWallet.ts
import { getNetworkConfig } from "../config/env";
const LOCALHOST_NETWORK = getNetworkConfig(); // ✅ From environment
```

## Environment Validation

Both configuration files include validation:

- ✅ **Required variables check** - Fails fast if variables are missing
- ✅ **Format validation** - Validates URLs, addresses, numeric values
- ✅ **Type checking** - Ensures correct data types
- ✅ **Development vs Production** - Different validation rules
- ✅ **Clear error messages** - Tells you exactly what's wrong

## Usage Commands

```bash
# 1. Start blockchain (reads from Blockchain/.env)
cd Blockchain
npm run node

# 2. Deploy contract (creates frontend/.env.local)
cd Blockchain
npm run deploy:localhost

# 3. Start frontend (reads from frontend/.env.local)
cd frontend
npm run dev
```

## Benefits

1. **🔒 Security**: No sensitive values in code
2. **🔧 Flexibility**: Easy to switch between networks
3. **✅ Validation**: Catches configuration errors early
4. **📝 Documentation**: Clear what each variable does
5. **🤖 Automation**: Frontend config auto-generated
6. **🔄 Consistency**: Same config used everywhere

## Troubleshooting

### "Missing required environment variables"

- Copy `.env.example` to `.env` and fill in values
- Check all required variables are set

### "Environment validation failed"

- Validate URLs are properly formatted
- Ensure chain IDs are numeric
- Check contract addresses are valid Ethereum addresses

### "Wrong network" errors

- Verify `CHAIN_ID` matches your blockchain
- Ensure `RPC_URL` is accessible
- Check MetaMask is connected to correct network
