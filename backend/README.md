# TradeChain Backend Listener

This backend service subscribes to events emitted by the deployed `TradeChain` contract, logs each event payload, and incrementally writes trade state into MongoDB.

## How it gets blockchain config

It loads values in this order:

1. `backend/.env` (if provided)
2. `frontend/.env.local` generated by your deploy script

This means your current deployment flow already provides everything needed for the listener.

## Setup

```bash
cd backend
npm install
```

(Optional) create `backend/.env`:

```bash
RPC_URL=http://127.0.0.1:8545
CONTRACT_ADDRESS=0xYourContractAddress
MONGODB_URI=mongodb://127.0.0.1:27017
MONGODB_DB_NAME=tradechain
PORT=4000
POLLING_INTERVAL=1000
FRONTEND_ENV_PATH=../frontend/.env.local
```

## Run

```bash
cd backend
npm start
```

You should see logs like:

```text
Backend listener server running on http://localhost:4000
Subscribed to TradeChain events at 0x...
[EVENT] TradeCreated -> {...}
```

## Health check

`GET http://localhost:4000/health`

Returns current RPC/contract settings and latest block number.
